# Standups

This directory contains weekly standup summaries for Team Satisfaction during the V-Beta capstone project.

## Overview

Each standup captures:

- Accomplishments Last Week
- Plans for This Week
- Blockers / Issues
- Weekly status health

## Status Legend

- 🟢 **Green** = on track
- 🟡 **Yellow** = moderate risk / needs attention
- 🔴 **Red** = off track / major blockers

## File Naming Convention

Use one file per standup with this format:

- `YYYY-MM-DD-standups.md`

Example:

- `2026-04-20-standups.md`

## Recommended Template

```md
# Standup - Team Satisfaction - YYYY-MM-DD

## Project
V-Beta

## Week Status
- **Overall:** 🟢 Green / 🟡 Yellow / 🔴 Red

## Accomplishments Last Week
- [Text]
- [Text]

## Plans for This Week
- [Text]
- [Text]

## Blockers / Issues
- [Text]

## Notes
- [Optional]
```
